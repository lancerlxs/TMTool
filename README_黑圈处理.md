# 黑色圆圈检测与裁剪工具使用说明

## 功能概述

本工具专门用于检测和裁剪JPG图像文件中位于左侧或右侧的黑色不规则圆圈。适用于扫描文档、档案图片等需要去除边缘标记的场景。

## 主要特性

1. **智能检测**：自动识别图像左侧或右侧的黑色圆圈区域
2. **边距限制**：仅在距离边缘指定范围内检测（默认40mm/4cm）
3. **尺寸限制**：可配置圆圈最大直径（默认25mm/2.5cm）
4. **批量处理**：支持递归处理目录及子目录下的所有JPG文件
5. **预览对比**：提供处理前后的并排预览效果
6. **日志记录**：详细记录每个文件的处理状态和检测结果
7. **Windows 7兼容**：完全兼容Windows 7操作系统

## 运行环境要求

## 使用方法

### 方式一：直接运行Python脚本

```bash
python BlackCircleRemover.py
```

### 方式二：使用打包后的exe程序

1. 双击运行 `build_blackcircle.bat` 进行打包
2. 在 `dist\BlackCircleRemover\` 目录下找到 `BlackCircleRemover.exe`
3. 将整个文件夹复制到目标机器即可使用

## 操作步骤

### 1. 选择输入目录
- 点击"选择文件夹"按钮，选择包含待处理JPG文件的目录
- 程序将递归扫描该目录及其所有子目录

### 2. 设置输出目录
- **自动模式**（推荐）：勾选"自动在源目录下创建'图像处理结果'目录"
  - 程序会在输入目录下自动创建"图像处理结果"文件夹
  - 处理后的文件按原目录结构保存
  
- **手动模式**：取消勾选，手动选择输出目录
  - 适合需要将结果保存到特定位置的场景

### 3. 配置圆圈参数
- **圆圈最大直径**：设置要检测的圆圈的最大直径（单位：毫米）
  - 默认值：25mm（2.5cm）
  - 可调范围：5mm - 50mm
  - 仅直径小于等于此值的圆圈会被处理

- **检测边距范围**：设置从图像边缘开始检测的范围（单位：毫米）
  - 默认值：40mm（4cm）
  - 可调范围：10mm - 100mm
  - 仅在左右两侧各此范围内检测圆圈
  - 中间区域的黑色标记不会被处理

### 4. 开始处理
- 点击"开始处理"按钮
- 进度条显示当前处理进度
- 日志框实时显示每个文件的处理状态
- 如需停止，点击"停止处理"按钮

### 5. 预览效果
- 处理完成后，"预览效果"按钮变为可用
- 点击可查看第一个检测到圆圈的文件的处理前后对比
- 左侧显示原图，右侧显示处理后的图像

### 6. 查看日志
- 日志框显示详细的处理信息：
  - 每个文件的处理状态（成功/失败）
  - 检测到的圆圈数量
  - 错误信息（如有）
  - 处理统计汇总

## 技术原理

### 检测算法
1. **灰度转换**：将彩色图像转换为灰度图
2. **阈值分割**：使用阈值50提取黑色像素区域
3. **边距区域划分**：根据配置的边距，划分左右两侧检测区域
4. **连通分量标记**：使用BFS洪水填充算法识别独立的黑色区域
5. **尺寸过滤**：根据配置的直径限制筛选符合条件的圆圈
6. **位置判断**：仅在左右两侧边距范围内检测，中间区域不处理

### 裁剪方法
- 使用白色椭圆覆盖检测到的黑色圆圈区域
- 自动添加10%的半径作为边缘容差
- 确保坐标在图像范围内，避免越界

## 注意事项

1. **图像格式**：仅支持JPG/JPEG格式文件
2. **颜色假设**：假设背景为白色或浅色，圆圈为深色
3. **性能考虑**：大尺寸图像（超过4000x4000）可能处理较慢
4. **内存占用**：批量处理大量文件时注意内存使用情况
5. **原始文件保护**：程序不会修改原始文件，所有结果保存到输出目录

## 常见问题

### Q: 为什么有些圆圈没有被检测到？
A: 可能的原因：
- 圆圈直径超过了设定的最大值
- 圆圈颜色不够深（灰度值高于阈值50）
- 圆圈形状过于不规则，无法被识别为连通区域
- **圆圈不在两侧边距范围内**（默认只检测距离边缘40mm内的区域）

### Q: 如何处理非圆形的黑色标记？
A: 当前版本主要针对圆形/椭圆形标记。如需处理其他形状，可以调整代码中的检测逻辑。

### Q: 处理后的图像质量如何？
A: 程序使用95%的JPEG质量保存，基本保持原图质量。白色覆盖区域可能与原背景有轻微差异。

### Q: 可以在Linux或Mac上使用吗？
A: 理论上可以，但需要测试兼容性。当前版本针对Windows 7优化。

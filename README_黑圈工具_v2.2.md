# 黑色圆圈检测与裁剪工具 - v2.2

## 📋 项目简介

这是一个专为Windows 7环境设计的JPG图像黑色圆圈检测与裁剪工具，支持智能边界检测和多线程并行处理。

### 核心功能

✅ **智能边界检测**：自动识别文字和竖线，仅在边缘区域检测圆圈  
✅ **多线程处理**：默认4线程，可调1-16线程，提升处理速度2-4倍  
✅ **批量处理**：递归扫描目录及子目录下所有JPG文件  
✅ **预览对比**：同时展示处理前后的效果  
✅ **日志记录**：详细的处理过程和结果统计

## 🎯 使用场景

### 场景1：少量文件快速处理
- **适用**: <10张图片
- **建议线程数**: 2-4
- **预期加速比**: 1.5-3x

### 场景2：大批量文件处理
- **适用**: >50张图片
- **建议线程数**: 6-8
- **预期加速比**: 3-4x

### 场景3：高分辨率图片
- **适用**: 图片尺寸>2000x3000
- **建议线程数**: 2-4
- **原因**: 减少线程切换开销

- **适用**: 双核CPU或内存<8GB
- **建议线程数**: 1-2
- **原因**: 避免资源竞争

## 🔧 技术特性

### 1. 智能边界检测
- 自动识别页面中的文字位置
- 检测长竖线位置
- 根据内容智能确定检测区域
- 如无文字和竖线，则全图检测

### 2. 多线程架构
- 使用ThreadPoolExecutor实现并行处理
- 线程锁保护共享资源
- 异步任务提交与结果收集
- 完全兼容Windows 7

### 3. 圆圈检测算法
- BFS连通分量标记（自实现，无需scipy）
- 形状特征分析（高度、宽高比、像素密度）
- 阈值分割（灰度值<50判定为黑色）
- 白色填充裁剪

## ⚠️ 常见问题

### Q1: 圆圈未被检测到？
**可能原因**:
- 圆圈太小或颜色不够深
- 被识别为文字内容的一部分
- 需要调整检测参数

**解决方案**:
1. 增大"圆圈最大直径"到30-40mm
2. 降低黑色阈值（修改代码第126行）
3. 参考《黑圈检测问题排查指南.md》

### Q2: 多线程没有提速？
**可能原因**:
- 文件数量太少（<5张）
- 单张图片太小（处理时间<0.5秒）
- CPU核心数不足

**解决方案**:
- 增加测试文件数量到20+
- 检查CPU使用率是否达到预期
- 尝试不同线程数对比

### Q3: 程序卡死或无响应？
**解决方案**:
- 降低线程数到2-4
- 检查日志中的错误信息
- 使用"停止处理"按钮中断
